# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-08-01

### Added
- Enhanced README with badges, table of contents, and citation section.
- GitHub issue templates for bug reports and feature requests.
- Pull request template.
- Full documentation suite: THEORY.md, HARDWARE_DESIGN.md, FIRMWARE_ARCH.md, SOFTWARE_ARCH.md.
- Complete firmware source: main.ino, scanner.h/.cpp, mux.h/.cpp, protocol.h.
- Complete Python software: receiver.py with threaded serial acquisition, visualizer.py with Tkinter GUI.
- Hardware: BOM.csv (machine-readable), schematic_notes.md with full connection guide.
- .gitignore for Python, Arduino, and IDE artifacts.
- CONTRIBUTING.md with PR template and style guidelines.
- ACKNOWLEDGMENTS.md with references and tools.

### Changed
- Repository structure standardized to English-only.
- All documentation rewritten for clarity and international audience.

## [0.1.0] - 2026-01-15

### Added
- Project concept and initial commit.
- Carbon film resistive sensing principle defined.
- Two-stage scanning algorithm designed.
